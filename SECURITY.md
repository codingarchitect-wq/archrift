# Security

archrift runs on your machine and reads your code; nothing leaves it unless you
use the Ask bar, which hands the question to the Claude Code CLI you have
installed and signed in to (read-only tools, a deny list for secret files).
`archrift serve` listens on 127.0.0.1 only.

To report a vulnerability, please use GitHub's private reporting: the
repository's **Security** tab → **Report a vulnerability**. Please don't open a
public issue for it. You'll get an answer within a week.

Supported: the latest release.
